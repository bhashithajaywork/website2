# Automatic AI posts

This adds a robot writer: a few times a day, GitHub runs a small script that
asks Google's Gemini (free) to write a short post (rotating between Living,
Work, and Culture) — plus a matching cover image generated by Pollinations.ai
(also free, no account needed) — and saves it straight to your Supabase
database. Nothing needs to run on your own computer — GitHub does it for
free, on schedule.

This uses Google's Gemini API for the writing, not Anthropic's, because
Gemini has a real free tier — no credit card, no expiry, roughly 1,500
requests a day, which is far more than the 3 a day this needs. One
trade-off: on the free tier, Google may use your prompts to improve their
models. That's fine for auto-generated blog posts, but worth knowing.

Images come from Pollinations.ai, which generates an image on the fly from
a short description Gemini writes for each post, and returns it at a URL
you can use directly — no upload step, no storage bucket, no account.

> **If your `articles` table doesn't have an `image_url` column yet**, add
> it once in Supabase's SQL Editor:
> ```sql
> alter table articles add column image_url text;
> ```

## 1. Get a free Gemini API key

1. Go to https://aistudio.google.com and sign in with a Google account.
2. Click **Get API key → Create API key**. No payment details needed.
3. Copy the key.

## 2. Get your Supabase service role key

In your Supabase project, go to **Project Settings → API**, and copy the
**service_role** key (not the anon key you used before — this one has full
access, so it must never go in the website's `.env` or frontend code).

## 3. Add secrets to GitHub

In your GitHub repository: **Settings → Secrets and variables → Actions →
New repository secret**. Add three secrets:

- `SUPABASE_URL` — your Supabase project URL (same one from before)
- `SUPABASE_SERVICE_ROLE_KEY` — the service_role key from step 2
- `GEMINI_API_KEY` — the key from step 1

## 4. Push these new files

If you haven't already, add the new files to your existing repository:

```bash
git add .
git commit -m "Add automatic AI posting"
git push
```

## 5. Test it

Go to your repo's **Actions** tab, click **Auto-publish post** on the left,
then **Run workflow** to trigger it once by hand. After it finishes (usually
well under a minute), check your live site — a new post should appear.

## Adjusting it

- **How often it runs**: edit the `cron` line in
  `.github/workflows/auto-post.yml`. It's currently `0 */8 * * *` (every 8
  hours, 3 times a day). For once a day, use `0 9 * * *` (9am UTC). For
  every 4 hours, use `0 */4 * * *`. Stay well under 1,500 runs a day and
  you'll stay inside the free tier.
- **What it writes about**: edit the `CATEGORIES` list near the top of
  `scripts/generate-post.mjs`.
- **Writing style**: edit the prompt text inside `generatePost()` in the
  same file.
- **Image style**: the same prompt asks Gemini for an `image_prompt` for
  each post — tweak the instruction there to nudge the look (e.g. "a muted,
  film-photography style") if the images feel off.
- **If the model name ever stops working**: Google renames and retires
  Gemini models fairly often. Check
  https://ai.google.dev/gemini-api/docs/models for the current free-tier
  model, and update the `MODEL` constant near the top of
  `scripts/generate-post.mjs`.
- **Turning it off**: delete `.github/workflows/auto-post.yml`, or disable
  the workflow from the Actions tab.

Auto-posts show up in Admin like any other post, so you can still edit or
delete anything it writes.

## Optional: auto-post to a Facebook Page (via Zapier — no developer setup)

Every time a post is published, it can also be shared to a Facebook Page,
with a real link straight to that article — no Facebook Developer account,
no App Review, no token juggling. This uses two things: a live RSS feed
this project already includes at `/api/rss`, and Zapier's free plan to
watch that feed and post new items to Facebook.

### 1. Make sure the RSS feed is live

Once you've deployed the latest code, visit:
```
https://your-domain.com/api/rss
```
You should see XML listing your posts. If you see an error about missing
Supabase environment variables, add `VITE_SUPABASE_URL` and
`VITE_SUPABASE_ANON_KEY` in your Vercel project's **Settings →
Environment Variables** (the same values from your original site setup).

### 2. Create a free Zapier account

Go to https://zapier.com and sign up — no credit card needed.

### 3. Build the Zap

1. **Create Zap → Trigger**: search for and choose **RSS by Zapier**, event
   **New Item in Feed**.
2. Paste your feed URL from step 1, then test the trigger — it should pull
   in your most recent post.
3. **Action**: search for and choose **Facebook Pages**, event **Create
   Page Post**.
4. Click **Sign in to Facebook Pages** and connect your account — Zapier
   handles the login and permissions, no app creation needed. Choose your
   Page.
5. Map the fields: **Message** → combine the RSS item's Title and
   Description fields, **Link** → the RSS item's Link field.
6. Turn the Zap **on**.

That's it — Zapier checks the feed roughly every 15 minutes on the free
plan and posts anything new to your Page, using this one Zap (well inside
the free plan's 100-tasks-a-month allowance for 3 posts a day).

### Notes

- The free plan checks the feed every ~15 minutes, not instantly — a post
  may take up to that long to appear on Facebook.
- If you ever want it faster or need more automations, Zapier's paid tier
  adds shorter polling and multi-step Zaps — not necessary for this.
